# claude-skills

Claude Code plugin marketplace.

## Install

```
/plugin marketplace add <github-user>/claude-skills
/plugin install mirpoll@kaiyrkhan-skills
```

## Plugins

- **mirpoll** — `/mirpoll [task]`. Indexes the codebase into `docs/modules/*.md`, interviews you until the plan is confirmed, then writes a spec with DoR/DoD per item and waits for approval before coding.
